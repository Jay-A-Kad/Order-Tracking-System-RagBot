# Returns Policy

## Return Window

Most items may be returned within 30 days of the delivery date shown in your order history. The return window is calculated from the date an order's status changed to "Delivered," not from the order's original placement date. Items returned after 30 days from delivery are not eligible for a standard return and will be handled on a case-by-case basis.

## Eligibility for Return

To be eligible for return, an item must be:
- In its original, unused condition
- In its original packaging, where applicable
- Accompanied by the order ID it was purchased under

Items marked as final sale at the time of purchase, and any item that has been used, installed, or altered, are not eligible for return.

## How to Start a Return

To start a return, provide your order ID and the item you would like to return. Once a return is approved, you will receive return instructions, including whether a prepaid return label is provided or whether return shipping is the customer's responsibility. Returns must be shipped back within 14 days of the return being approved, or the approval may expire.

## Order Status and Returns

An order can only be returned once it has reached "Delivered" status. Orders that are still "Processing," "Shipped," or "Out for Delivery" cannot be returned yet, since they have not been received. If you no longer want an order that has not yet shipped, that is a cancellation, not a return — see the cancellation policy for orders still in "Placed" or "Processing" status.

## Exchanges

We do not process direct exchanges. If you would like a different size, color, or product, please return the original item for a refund and place a new order for the item you want.

## Non-Returnable Items

Certain categories of items cannot be returned for hygiene, safety, or regulatory reasons. If an item you purchased is non-returnable, this will be noted on the product listing at the time of purchase.

## Return Shipping Costs

If a return is due to our error — for example, the wrong item was shipped, or the item arrived damaged — we cover return shipping costs in full. If a return is for any other reason, such as a change of mind, standard return shipping costs may apply unless a promotion states otherwise.
